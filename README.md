# Coach · 王者万象棋香香实时教练

本地优先、**只读屏幕** 的 Windows 桌面辅助。手动框选屏幕，使用 DeepSeek Vision / Ollama / OpenAI 读取局面，返回拿牌、升本、刷新、武器改造及对阵建议。只做建议，不自动点击、不读内存、不抓包。

## 启动

安装 Python 3.10+，运行 `run.bat`，或运行 `python -m pip install -r requirements.txt && python coach.py`。默认 `DeepSeek 云端 / deepseek-flash`，输入 `DEEPSEEK_API_KEY` 或在窗口输入 API Key。也可切换本地 Ollama（先 `ollama pull gemma3:4b`）或 OpenAI。

1. 选择显示器，点击「选取屏幕区域」，框选游戏窗口（不要把账号、聊天或密码框包含进来）。
2. 普通战斗使用「常规建议」。游戏内打开**公共牌库剩余数量面板**，切换「牌库扫描」并按「分析一次」。只记录模型认为明确可读的数字。
3. 打开**对手阵容面板**，切换「对手侦察」并分析一次。按对手可见姓名记录阵容与主要威胁。
4. 返回常规建议，模型将使用此前扫描过的带时间戳的快照辅助决策。注意：**记录会过期，绝非实时同步的牌库真值**。每次新对局点击「新开一局（清空记录）」。
5. 点击「开始监看」定时分析，默认 20 秒。未变化截图会跳过云端调用。每局默认最多 100 次调用。

## 使用边界与成本

- 牌库数据来自视觉扫描，仅当 `scene=pool_panel`、`panel_readable=true`、单条 `confidence=high` 且数量合法时更新；不臆测对手购买所减少的确切库存。`engine.TIERS` 当前为第三方校准的每英雄 1–5 阶库存：14/11/9/7/6；版本更新后需核对。没有可靠读取时保留旧快照并注明时间。
- 对手截图只在「对手侦察」模式下更新。不能从普通场上推断其他玩家阵容。由于模型识别有误差，战术建议仍需人工确认。
- DeepSeek `deepseek-flash` 支持图像输入、关闭思考模式以优先速度与成本；JPEG 图片转换为 tokens 后参与计费。最新价格参见 https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ 。接口结构参考 https://api-docs.deepseek.com/guides/vision/ 。
- 默认不上传截图；每次点击开始、手动分析进入云端前均需确认。只在内存中保留局面摘要，默认不存储截图/API Key。程序退出后状态消失，不保证云端服务商不记录请求。
- 不支持后台读取游戏隐藏状态、不提供精确抽卡概率、不保证在回合截止前返回。部分全屏窗口无法截图，请改窗口化。用户需自行确认游戏规则是否允许实时第三方辅助。
- 这是可运行的原型，已包含基本单元测试，但**尚未用真实游戏客户端与 DeepSeek 账号端到端验证**。

## 后续方向

- 将牌库与对手面板做成独立高分辨率扫描区，提高小字准确率。
- 引入人工确认/纠错与回合时效规则，避免旧牌库误导新局势。
- 在有准确的商店概率表和库存快照后增加追牌概率计算，而不是让语言模型随意猜概率。
- 针对不同对手阵容形成可解释的武器、站位和变阵策略引擎。
